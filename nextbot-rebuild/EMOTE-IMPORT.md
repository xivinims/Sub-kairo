# User-supplied R6 pack integration

Original upload: 20+ R6 Emote Animations.rbxm. The November 5 reattachment is byte-for-byte identical to assets/emotes.part0 through part6 concatenated (1,210,893 bytes; SHA-256 `acc4f67fa3e686020dc7e4ed1302770156eb106837958ed691ae0acfa4546995`). The audit reconstructs assets/user-r6-emotes.rbxm from those chunks.

Binary inspection found 19 KeyframeSequences, 4,453 keyframes and 33,690 poses; no Sound, Animation, Script, LocalScript or ModuleScript instances. The title's 20+ count does not match the actual sequence count.

The build copies all 19 sequences without modifying their keyframes, poses, easing or loop flags. IDs are stable slugs derived from their original names. Original model is kept as source, not inserted with its dummy into the map.

Catalog/shop integration and atomic DataStore purchase/equip logic are included. Provisional price: 250 internal coins each (chosen configuration, not an Evade price). No Robux transaction. Coins start at zero and are earned through survival, rescues and missions. ExactRunProfiles_v2 stores the shared economy and migrates NextbotEmotes_v1 only when a new profile is first created. Six equip slots are stored persistently. Selecting an inventory slot sets the slot used by EQUIPAR; the in-round emote selector plays an equipped emote.

R6 Pose playback uses Motor6D.Transform on each observing client, synchronized with server timestamps. Playback and previews share PosePlayer, which chooses the highest-weight pose for duplicate joint names at a timestamp and retargets from the pack's original R6 joint bases. The source clips are unchanged. Local movement/jump cancellation and the server's horizontal root velocity check cancel playback; Humanoid.MoveDirection alone is not a reliable server movement signal. Death, leaving the arena, character replacement and nonloop clip completion also cancel playback. This is a custom runtime preserving the source pose data, not Roblox Animator playback; exact easing/replication/streaming behavior needs in-engine validation. R15 playback is rejected.

The supplied Advanced Emote Wheel System.rbxl was opened by deserializing its binary instance data without executing any embedded Lua source. `assets/emote-wheel-reference.b64` preserves the original 189,838 bytes. ImportEmoteReference copies only StarterGui.EmotesUI as EmoteWheelTemplate and removes executable scripts, remotes, sounds and viewport runtime objects. The original wheel uses image `5221791428`, four radial Slot buttons, EmoteViewport avatar previews, EmoteName labels, AddEmoteButton and a separate searchable EmoteMenu. Those actual UI instances and assets are reused. The reference's toolbox demo AnimationIds, TopbarPlus scripts, remotes and DataStore code are not inserted into the running game.

EmoteWheel adapts the four radial positions to the six persistent slots using pages 1–4 and 5–6. Tapping an equipped slot plays it; tapping an empty slot or holding an equipped slot opens the owned-only equip search. Previews animate the player's cloned R6 avatar from the supplied keyframes. The original ring/slot layout is scaled to the safe HUD viewport and includes close/back/stop controls. Shop purchases still use the existing server-owned catalog and shared profile. A visual client playtest remains necessary; an instance import or successful compilation is not visual approval.

Music: the file contains none. Jumpstyle is configured with Creator Store audio 1839246711 (https://create.roblox.com/store/asset/1839246711/Jumpstyle), a selected accompaniment, not a verified original Evade track. Playback permissions and beat alignment have not been verified. Electro Shuffle is also configured with 1847238776. The other 17 have no audio associated. Playback supports per-emote audio, spatial range, common start timestamp, loop and EmoteVolume settings group.

Tests: duplicate purchases, insufficient funds, invalid prices, slot bounds, unowned equip rejection, no mutation of input balance. File count and compilation asserted by build. The real Roblox engine also checks all 19 sequences applying nonidentity transforms to the R6 rig. Zero-duration static poses remain active until canceled. Publication status is recorded in published-test.json; visual equivalence and a human client playtest are not certified.
