# Dead Signal: map-only build

Active build: `dead-signal-map-focus-v3`. Universe `9421311218`, Place `118064584465155`, branch `dead-signal-publisher` exclusively.

The requested map `18509954401` remains the base. The read-only audit found 2,670 parts, no scripts, a large open park/complex, and no source parts named as doors. Mesh-vertex read access was denied by Roblox. The exported volume/ground sampling in `review/` is a technical layout aid, not a faithful rendered Roblox preview. The live place at the start of this review was version 156 with `BrambleWorld`; geometry auditing loaded the exact requested map separately and never saved that probe.

The active publisher now assembles `map-install.luau`, `map-dressing.luau`, `map-server.luau`, `map-client.luau`, and `map-validate.luau`. Creature/capture scripts and test GUI are not included. Chapter, arena and creature sources remain recoverable in Git and do not execute in this build. No menu, inventory or HUD is implemented in this pass.

Five original service pavilions are placed on verified flat, unobstructed ground near the park's reception, west workshop, east substation, northwest storage and northeast observation areas. Footprint placement checks corners, 15 studs of headroom, solid geometry, and visual hedge intrusion. Each pavilion streams atomically and has real window openings, brick/plaster wall variation, skirting, floor joints, roof beams, conduit, cable tray, ventilation and drainage. Purpose-specific objects include CRT reception desks/paperwork/toy displays, workshop repair equipment/tools/drawer, transformer cabinets/cooling fins/insulators, storage shelving and supported crates. Exterior benches, barrels, crates and warm pole lights complement the existing map vegetation. No floating explanatory signs are created.

Supplied door geometry `8593730677`, station mesh `9609111841`, and individually selected toy props `16390129962` are sanitized through SafeAssetImporter.Select. Props retain uniform scaling. Native source textures and colors remain intact; excessive non-glass reflectance is clamped. Upper tree branches/foliage stop blocking avatars while trunks and architecture retain collision.

Five sliding entrance doors and one workshop drawer use the existing DoorService. Door leaves slide in front of the masonry along a real rail; both-side fixed interaction controls support native F/touch prompts. DoorService's occupied-doorway protection remains active. Mechanical doors remain usable when lights are off, preventing power-loss traps. Six sector switches use the existing PowerService to disconnect the appropriate lighting consumer. Controls validate live avatars, distance and cooldown on the server; missing references report through DebugService.

Lighting starts on for map inspection, with restrained bloom, atmospheric depth, muted grading and environmental specular response. Lights activate within 115 studs, update at 0.3 seconds, and at most four nearby lights cast shadows. Workshop/substation fans animate locally only within 70 studs and stop with their sector power. There is no strobe, chase or jumpscare during map inspection.
