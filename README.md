# Kairo — Discord Bot

Landing page oficial do Kairo, construída em HTML, CSS e JavaScript puro e preparada para deploy na Vercel.

## Design

A interface segue uma direção editorial/mobile-first: hero visual em tela cheia, grid fino sobre o fundo, tipografia grande, detalhes em rosa, cards arredondados, seção escura de personalidade e blocos claros para recursos/comandos.

## Conteúdo

- Moderação
- Economia
- XP e ranking
- Missões e conquistas
- Perfil e utilidades
- Interações com o mascote Kairo
- Busca e filtro de comandos
- Layout responsivo para celular e desktop
